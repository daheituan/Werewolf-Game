# 圆桌玩家 · 完整优化版

## 项目类型
这是普通微信小程序项目，不是微信小游戏项目。请在微信开发者工具中按“小程序”导入。

## 本版更新
1. 首页、游戏库、房间、我的四个入口已经补全。
2. 首页圆桌、头像、邀请按钮、人数统计、按钮质感已重做，更接近设计稿。
3. 设置页、规则页、联机身份查看页、游戏进行页、投票页、结果页已统一成卡通派对风格。
4. 身份逻辑已修正：
   - 不再提示“把手机递给下一位玩家”。
   - 玩家只在自己的设备查看自己的身份。
   - 游戏结束前不公开其他玩家身份。
   - 点击“结束并公开身份”后，结果页才显示全员身份。
5. 增加 `utils/roomService.js` 作为联机状态层：
   - 默认使用本地模拟，导入即可编译预览。
   - 后续可打开 `utils/config.js` 中的 `USE_CLOUD` 并配置云开发环境。
6. 增加 `cloudfunctions/roomState` 云函数骨架，便于后续接入真实房间同步、投票同步和身份公开。

## 导入方式
1. 解压压缩包。
2. 微信开发者工具 → 导入项目。
3. 选择解压后的项目文件夹。
4. 项目类型选择“小程序”。
5. AppID 使用你自己的 AppID。
6. 点击编译。

## 云开发联机接入说明
默认配置：
```js
USE_CLOUD: false
```
这样可以离线预览。若需要真实多人联机：
1. 开通云开发。
2. 上传并部署 `cloudfunctions/roomState`。
3. 在 `utils/config.js` 填写 `CLOUD_ENV`。
4. 将 `USE_CLOUD` 改为 `true`。
5. 在 `utils/roomService.js` 中把本地存储接口替换为云函数调用或数据库监听。
