
# 圆桌玩家 · 微信小游戏完整优化版

## 项目类型
这是微信小游戏项目，根目录包含：
- game.json
- game.js
- project.config.json

请在微信开发者工具中选择“小游戏”导入。

## 本版重点
1. 解决 `game.json: 未找到 game.json 文件` 问题。
2. 不再使用普通小程序的 `app.json / pages / wxml / wxss` 入口。
3. 全部界面使用 Canvas 绘制：
   - 首页圆桌房间
   - 游戏库
   - 游戏分类
   - 游戏设置
   - 规则页
   - 联机身份查看
   - 游戏进行中
   - 投票页
   - 结果与身份公开
4. 身份逻辑已修正：
   - 不再出现“请将手机递给下一位玩家”
   - 每位玩家只在自己的设备查看身份
   - 游戏结束前不公开其他玩家身份
   - 点击“结束并公开身份”后才展示全员身份

## 真正联机扩展
当前 `game.js` 中的 `syncRoomState()` 与 `updateRoomState()` 是本地模拟层。
后续可把这两个函数替换为：
- 微信云开发数据库监听
- 云函数
- WebSocket 房间同步

## 导入方式
1. 解压 zip。
2. 微信开发者工具 → 导入项目。
3. 项目目录选择解压后直接包含 `game.json` 的文件夹。
4. 类型选择“小游戏”。
5. 使用你的 AppID：wxc866a2fc983940a7。
6. 编译 / 预览 / 真机调试。
