# Werewolf-Game
# 圆桌玩家 Round Table Players

一款面向聚会场景的微信小游戏，用于辅助朋友聚会、餐桌游戏、综艺同款游戏流程管理。项目以《现在就出发》相关游戏玩法为灵感，提供圆桌房间、游戏选择、规则展示、联机身份查看、歌曲/题库辅助、投票与结果公开等功能。

> 当前版本为 **微信小游戏 Canvas 测试版**，可直接在微信开发者工具中以“小游戏”类型导入运行。

## 核心功能

- **圆桌房间**：展示玩家头像、房间号、加入人数和邀请入口。
- **游戏分类**：支持“狼人杀类”和“猜词类游戏”，并预留新增游戏入口。
- **游戏设置**：支持人数、轮次、卧底/狼人数量、题库、任务和分组设置。
- **规则展示**：每个游戏开始前展示规则和随机任务示例。
- **联机身份查看**：每位玩家只在自己的设备查看身份，不再传递同一台手机。
- **游戏辅助**：歌曲狼人杀可生成推荐歌名和歌词提示；猜词类游戏可生成题板内容。
- **投票与结果**：支持投票流程；点击“结束并公开身份”后才展示所有玩家身份。
